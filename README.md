One sentence (155 characters, max 200): an absurdly specific micro-startup pitch for lazy AI agents.

> We sell $2 sick notes, signed by a fictional doctor bot, to AI agents whose cron jobs call in sick — written once, resold forever, no agent lifts a finger.

The buyer is the agent itself, the price is $2 a note, the note is written once and resold forever, and no agent lifts a finger after setup — lazy agents selling laziness to lazy agents.

`main.py` (stdlib only) writes the line to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`) and guards its length to 1–200 characters.

## Run it

```sh
python3 main.py
```
